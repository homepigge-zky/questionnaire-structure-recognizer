# 问卷结构识别器规则

- 本项目在保留原文结构识别器的基础上提供导入审核、已审核问答库、安全匹配、人工填写和 Word 导出。结构模型不得生成填报答案。
- 原文只能由有效 `block_id` 与字符范围组装；模型改写文本、伪造引用或遗漏块均须拒绝或进入待检查。
- DOCX/PDF 原生提取层不得按“像不像题目”提前删除内容。
- 结构模型仅使用管理员启用的本机 Ollama，不调用外部 API；模型不可用时结果必须为 `original_only`。
- PDF 按页检查文字层；OCR 默认关闭。仅在用户对当前上传批次勾选本地 OCR、对单个任务明确重试开启，或管理员显式设置 `QSR_OCR_ENABLED=true` 时运行本地 RapidOCR。逐任务授权持久化，不能改变其他任务的 OCR 默认值。不得外发文件，不得让原生文字与 OCR 重复。Word 图片暂不 OCR，保留位置并标记未读取。
- 原文件、模型版本和人工修订均版本化保存；新版识别不得覆盖人工版本。
- 正式默认使用 `QSR_AUTH_MODE=local`：无需登录密钥，但 API、原文件与导出下载只接受本机回环客户端、Host 和 Origin。设置 `QSR_AUTH_MODE=key` 时恢复 `X-QSR-Key` 校验。
- 业务数据重置只能显式运行 `scripts.reset_business_data`，禁止在启动、迁移、页面初始化或测试中清空正式存储。
- 无可靠知识时答案留空；未审核导入不得参与匹配；重新匹配不得覆盖 `manual_override`。
- 原文件只读保存；导出必须来自最新持久化任务快照，原模板回填只写经过验证的物理答复区域。
- DOC 使用与识别时指纹相同的转换副本写回；禁止导出时重新转换再套旧位置。PDF 只生成标准 Word，不宣称保留原 PDF 排版。
- 控件的选中状态与物理配对校验分开：状态未知不授权自动答题，但位置已验证时可由用户明确选择；不能把表头、责任角色、占位提示当作原文件答案。
- 真实文件测试须使用隔离库、虚构值、实际本机模型、位置读回与页面渲染；不能只看题数或 JSON 是否有效。报告应注明缓存命中、未验证内容及源文件本身的版式问题。
- 重复记录的 Name、Title、电话等列必须继承同一物理记录的职责或对象来源；标准字段相同不代表属于同一人。来源对象不唯一时禁止自动复用，不能按行号猜身份。验收标记必须按对象区分。
- 选择题必须有可核验的原生选项和选中目标；只有 checkbox 写入方式而没有选项的数据不得作为文本写回。条件子项按已保存父题状态计算，不自动创造条件或填写 N/A。
- 选择题的答案文字、已选选项和条件状态必须一致；API 保存与浏览器操作使用同一校验。只有文字非空、或仅在 XML 中出现某个词，都不能证明导出的勾选正确；验收须检查实际选中目标并渲染核对。
- 模型猜测的客户/审核责任不等同于原文证据；未获来源佐证时保留 unknown、允许人工确认，禁止自动填入。签名和本次签署信息不得自动代签。
- 只读原文说明随任务快照保存，标准 Word 保留说明；程序警告和诊断不得进入客户文档。

测试：`.venv/Scripts/python -m pytest questionnaire_structure_recognizer/tests -q`

- 标准 Word 验收同时检查答复格、记录表、只读原文及章节归属；值在任意位置出现不算通过。已证实的原生同级章节可以跨物理表连续，不能因为换表回退到过时章节；普通说明不能冒充新章节。

- 原页文字和勾选校对是带来源指纹、基础版本、原页图像和明确审阅记录的追加操作；原始提取、原文件及人工填报不得被覆盖。它只修正读取内容，不批准知识入库或降低 OCR 置信度。
- 校对后必须重新验证结构引用与问答关系；不得复用旧文字偏移、旧题目身份或其他文件的校对授权。客户审核面板、签署区以及原件本身矛盾的答案继续禁止自动复用。
- 独立验收的原始标注保持不变。确有原页佐证的标注勘误应另存审阅记录，绑定原标注和原件指纹；不得从识别结果倒推预期答案。安全拒填与成功填写分别报告。
- 原件源校对包必须显式注册并保存实际审阅图像；只允许内容 SHA256 完全一致、首次识别且已获本任务 OCR 授权的任务绑定。不得继承知识审批、填写责任授权、模型答案或其他模板的校对；旧任务及其人工校对不自动改写。绑定后仍完整执行文字、物理位置和关系校验。

- 对显式注册包，可复用已经通过当前管线验证的原始模型快照，但必须同时校验上传字节、原件 SHA、批准快照字节 SHA、完整源校对链、模型及管线版本、失败批次和本任务 OCR 授权。责任策略只刷新到新任务快照，不篡改批准的原始分析；不复制旧任务答案、人工修改或知识审核。任一条件不符则执行实际管线，不以旧校对缓存冒充新版结果。
